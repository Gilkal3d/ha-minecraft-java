Console do servidor

server.properties

Edite livremente e salve. O servidor precisa estar parado para aplicar. Opções novas exigem reiniciar o add-on (loader, versão, memória, mods do Modrinth).

Whitelist

NomeUUID

Ative a whitelist em server.properties → whitelist=true. Com o servidor online, o add-on usa RCON (aplica na hora); offline, edita o whitelist.json direto.

Instalar do Modrinth

O slug é a última parte da URL do projeto (modrinth.com/mods/lithium). A versão compatível com o seu loader/versão do Minecraft é escolhida automaticamente, junto com as dependências obrigatórias.

Mods instalados

Alterações de mods exigem reiniciar o servidor (botão Reiniciar no topo).
